# DVLARegistrationTestSystem
DVLA Technical Assessment Solution using c#,.NET 8 and NUnit Automation tests
## Features
- Stores vehicle registration data in memory
- Returns total number of registration numbers
- Returns vehicle ID for a given registration number
- Includes NUnit unit tests

## Technologies
- C#
- .NET 8
- NUnit

## How to Run
Open the solution in Visual Studio and run the console application.

## How to Run Tests
Open Test Explorer in Visual Studio and select Run All Tests.
